# User Stories – AI-Powered Personal Knowledge Organizer

## User Story 1 – Create a Note
As a user, I want to create a note with a title and content so that I can save useful information in one place.

**Acceptance Criteria:**
- The user can enter a title and text content.
- The user can save the note.
- The saved note appears in the notes list.

**Priority:** MVP

## User Story 2 – Edit a Note
As a user, I want to edit an existing note so that I can update or correct its information.

**Acceptance Criteria:**
- The user can open an existing note.
- The user can modify its title and content.
- The changes are saved and displayed.

**Priority:** MVP

## User Story 3 – Delete a Note
As a user, I want to delete notes that I no longer need so that I can keep my workspace organized.

**Acceptance Criteria:**
- The user can select a note for deletion.
- The application asks for confirmation.
- The deleted note no longer appears in the notes list.

**Priority:** MVP

## User Story 4 – Organize Notes with Tags
As a user, I want to assign tags to my notes so that I can group related information.

**Acceptance Criteria:**
- The user can create or select tags.
- A note can have multiple tags.
- Tags are displayed with their associated notes.

**Priority:** MVP

## User Story 5 – Search Notes
As a user, I want to search notes by title or content so that I can quickly find specific information.

**Acceptance Criteria:**
- The user can enter keywords in a search field.
- Matching notes are displayed.
- A helpful message appears when no results are found.

**Priority:** MVP

## User Story 6 – Filter Notes by Tag
As a user, I want to filter notes by tags so that I can view information from a specific category.

**Acceptance Criteria:**
- The user can select a tag.
- Only notes associated with that tag are displayed.
- The user can clear the filter to see all notes again.

**Priority:** High

## User Story 7 – Generate AI Summaries
As a user, I want to generate a summary of a note using AI so that I can understand its main points more quickly.

**Acceptance Criteria:**
- The user can request a summary of an existing note.
- The application generates a concise summary based on the note's content.
- The summary is displayed separately from the original note.

**Priority:** High

## User Story 8 – Mark Notes as Favorites
As a user, I want to mark important notes as favorites so that I can access them quickly.

**Acceptance Criteria:**
- The user can mark and unmark notes as favorites.
- Favorite notes are visually distinguished.
- The user can view a list of favorite notes.

**Priority:** MVP

## User Story 9 – View Notes Dashboard
As a user, I want to see all my saved notes in an organized dashboard so that I can manage my knowledge efficiently.

**Acceptance Criteria:**
- The dashboard displays saved notes.
- Each note shows its title, creation date, and tags.
- Notes can be opened from the dashboard.

**Priority:** MVP

## User Story 10 – Receive Feedback on Actions
As a user, I want to receive confirmation or error messages when performing actions so that I know whether an operation was successful.

**Acceptance Criteria:**
- A success message appears after saving or deleting a note.
- An error message appears when an operation fails.
- Feedback messages are clear and easy to understand.

**Priority:** Medium
